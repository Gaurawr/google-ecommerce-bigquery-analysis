# 🛒 Google Ecommerce Analytics — BigQuery SQL Analysis

## Overview
Analysis of Google Merchandise Store real ecommerce data 
using BigQuery SQL — 1.9 million sessions, $51M+ revenue data.

## Tools Used
- 🗄️ BigQuery — Cloud SQL queries on Google's public dataset
- 📊 SQL — Advanced aggregations, CASE WHEN, DISTINCT counts
- 📁 Dataset: data-to-insights.ecommerce.all_sessions (Google Public Data)

## Dataset
- Total Sessions: 1,982,777
- Unique Visitors: 19,989
- Total Revenue: $51,008,1005.94 USD
- Source: Google Merchandise Store (Real Data — 2016/17)

## Business Questions Answered

### 1. Total Revenue Overview
- 1.9M+ sessions analysed
- $51M+ total revenue identified
- 2.29M total transactions processed

### 2. Top Cities by Revenue
- New York #1 — $57.9M revenue
- Mountain View #2 — $41.7M (Google HQ!)
- San Francisco #3 — $25.2M

### 3. Top Products by Revenue
- Nest Thermostat #1 — $873,834
- Nest Cam Outdoor #2 — $695,014
- Nest products dominate top 6 positions

### 4. Traffic Channel Conversion Rate
- Referral = highest conversion 17.81%
- Direct = 7.57%
- Social = lowest at 0.44%

### 5. Cart Abandonment Funnel
- Add to Cart: 122,477 visitors
- Checkout Started: 56,010 (45.73%)
- Purchase Completed: 19,988 (16.32%)
- 84% cart abandonment identified

## Key Business Insights
- Nest smart home products drive majority of revenue
- Referral traffic converts 40x better than Social media
- 84% cart abandonment = major revenue recovery opportunity
- Mountain View high sales due to Google employee purchases

## Skills Demonstrated
- BigQuery SQL on real Google Analytics data
- Advanced SQL — CASE WHEN, DISTINCT, aggregations
- Funnel analysis and conversion rate calculation
- Business insight generation from raw data
- Data anomaly detection and correction
